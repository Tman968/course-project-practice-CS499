# course-project-practice-CS499
Practice repository for CS499

GitHub Practice Reflection:
1. The purpose of a commit is to package all changed or added files to prepare an upload to the online repository.
2. A git push uploads data from your computer to the online repository. A git pull adds data to your computer from the online repository.
3. Branches prevent the loss of data from overlapping different users additions to the project.
4. Getting used to the terminal based uploading and committing system. VSCode has features I will learn for this project to more easily work with github.
5. Github is a great platform for teams to collaborate while coding without using a shared environment.
